# US-Oil-Gas-Production-Analysis
Exploratory Data Analysis and ML Forecasting on US Oil & Gas 
Production data from 2015-2017.

## Data Preprocessing
- Volume column cleaned — removed commas, converted to float
- Production Date converted to datetime format

## Insights Covered
- State wise total production analysis
- Commodity wise production comparison
- Production trend over years (2015-2017)
- Onshore vs Offshore production comparison
- Top 10 counties by production volume

## ML Model
- Linear Regression to forecast future production
- R2 Score and MAE reported

## Tools Used
Python, Pandas, Matplotlib, Sklearn

## Dataset
US Oil and Gas Production and Disposition 2015-2025 — Kaggle

## Target Companies
Baker Hughes, Shell, Schlumberger GCC
